# TASK-1: Implement getAllTasks API using GitHub Copilot

## Description

Currently, our system does not provide a method to retrieve all tasks. Your task is to implement a `getAllTasks` functionality, exposing it via the API. This should be done by:

- Adding a `GetAllTasks` method to the `ITaskService` interface (#file:ITaskService.cs).
- Implementing the method in the service and controller layers.
- Using only GitHub Copilot functionalities and recommended Edit Mode for code changes.

The goal is to enable clients to fetch a list of all tasks through the API.
